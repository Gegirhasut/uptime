# uptime

Внешняя проверка сервера игры «Подпольные бои: Лихие 90-е» (https://undergroundfightgame.com) — снаружи, не с самого
сервера: если ляжет машина у хостинга, проверка останется жива.

- **Раз в 5 минут** GitHub запускает `check.sh` (`.github/workflows/check.yml`): `/api/health` и чтение из базы
  (`/api/bots/version`), три попытки подряд.
- **Лёг** — пуш на телефон через [ntfy](https://ntfy.sh) («Сервер игры не отвечает»), пока лежит — напоминание раз в
  час; **поднялся** — «снова работает» и сколько лежал. Канал ntfy — в секрете репозитория `NTFY_TOPIC`.
- `state.txt` — что известно между запусками (`up|down`, с какого времени, когда напоминали), `OUTAGES.md` — все
  падения, `alive.txt` — раз в 20 дней, чтобы GitHub не выключил расписание (он выключает его через 60 дней без
  коммитов).
- Проверить руками: вкладка **Actions** → **check** → **Run workflow**.
